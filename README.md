# Nick Merich

Founder of [GRYT](https://grytrunclub.com), a Pittsburgh run club that produces artist-led athletic events. 10+ years running growth for music tech companies and home-services businesses. Most of what I publish here is operating knowledge written as agent skills: the playbooks I actually use, in a format any agent that reads `SKILL.md` can run.

## Skills libraries

| Repo | What it is |

## Product

- [gryt-5k-journey](https://github.com/nickmerich/gryt-5k-journey): landing pages and registration for GRYT 5Ks, including Run Takoma With Love.

## How the skills are built

Every skill is grounded in work we actually did, keeps counts honest (RSVPs, check-ins and unique runners are different numbers), and treats people's personal information as private by default. Each library ships with a validator and a script that turns a plain CSV export into a weekly report.

If you use one, open an issue and tell me what broke or what you changed. That is the most useful thing you can do.
